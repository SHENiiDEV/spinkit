# AI art prompts — giants slots

The 9 giants games (same math as Enchanted Knight) currently use procedural art from `node scripts/gen-art.js giants`.
To replace it with painted art, generate the 3 images below for a game and send them — they get cut out and wired in the same way as Enchanted Knight.

Files that get replaced in `public/games/<id>/assets/`: `stage.jpg` (1400×1254, reel panel at x 244, y 254, 914×853), `giant.png` and `wild.png` (400×1000, transparent corners), `cover.jpg` (lobby tile), plus symbol PNGs.

**Tips:** generate the cabinet with an EMPTY reel panel (no symbols), and symbols on a plain flat background so they cut cleanly.

### Import

```bash
G=public/games/tiki_titans/assets
python3 scripts/import-art.py stage  cabinet.png $G --windows 2,4,5,6,5,4,2   # prints theme.stage with reel_rects
python3 scripts/import-art.py strip  totem.png   $G/wild.png
python3 scripts/import-art.py card   giant.png   $G giant
python3 scripts/import-art.py sheet  symbols.png $G sym_scatter sym_turtle sym_parrot sym_shell sym_pineapple wild_icon shark_icon sym_hibiscus sym_coconut
python3 scripts/import-art.py sheet  cards.png   $G sym_a sym_k sym_q sym_j sym_10
node scripts/gen-art.js tiki_titans --cover http://localhost:3000                # lobby cover from the running server
```

### Animated giant (optional)

Image-to-video of the giant card (e.g. PixVerse, 5 s, seamless loop, static camera, the frame must not move), then:

```bash
python3 scripts/import-art.py video clip.mp4 giant_card.png $G giant --patch 266,20,404,60   # --patch: rectangles to repaint from the still (e.g. a watermark)
```

It writes `giant.webm`, `giant.mp4` (cropped to the card, no audio) and `giant_mask.png`; the symbol gets
`tall_video: [webm, mp4], tall_mask: mask` (the still `giant.png` stays as the fallback and for the paytable).

### Re-skin (same math, new theme)

1. Generate the same 5 pictures in a new theme (change the scene, the logo text, the Wild, the giant and the symbols in the prompts above).
2. Import them into `public/games/<new_id>/assets/` with the commands above (same file names).
3. Add `src/games/definitions/<new_id>.js` and register it in `definitions/index.js`:

```js
const { reskin } = require('../kit');
module.exports = reskin(require('./tiki_titans'), {
  id: 'aztec_titans', name: 'Aztec Titans', category: 'aztec',
  tagline: '9,600 ways · Full-reel Jaguar Wilds · Sticky x5–x5000',
  theme: { accent: '#ffcf3a', title: ['AZTEC', 'TITANS'], stage: { /* printed by import-art.py stage, plus image: '/games/aztec_titans/assets/stage.jpg' */ } },
  symbols: { WILD: { name: 'Jaguar Totem Wild' }, SHARK: { name: 'Serpent God' }, SCATTER: { name: 'Sun Temple' },
             TURTLE: { name: 'Jade Mask' }, PARROT: { name: 'Quetzal' }, SHELL: { name: 'Obsidian Knife' }, PINEAPPLE: { name: 'Cacao' } }
});
```

Paytable, reels, free spins, RTP and Feature Buy price stay exactly the template's (a test checks it spin for spin); no calibration needed.
