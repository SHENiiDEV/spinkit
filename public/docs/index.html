Error codes

UNAUTHORIZED401 — missing, invalid or revoked API token
IP_NOT_WHITELISTED403 — caller IP is not in the merchant whitelist
SIGNATURE_REQUIRED / INVALID_SIGNATURE / SIGNATURE_EXPIRED401 — request signing problems
MERCHANT_SUSPENDED / PLAYER_BLOCKED / GAME_DISABLED403
INVALID_BET400 — bet is not on the allowed bet ladder (see allowed_steps)
INSUFFICIENT_FUNDS / INSUFFICIENT_FLOAT400 — player balance / merchant float too low
DUPLICATE_TX_ID409 — tx_id reused for a different amount or player
TEST_PLAYER_REQUIRED / TEST_PLAYER_NO_WITHDRAW403 — QA options on a real player / withdrawal from a test account
INVALID_TOKEN401 — game session expired or revoked
